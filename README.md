# Валерия Фридлендер — версия 2

Вторая рабочая версия сайта персональных разборов через астрологию,
нумерологию и цифровую психологию.

- Открытый репозиторий: https://github.com/ivashkov2022-droid/valeria-fridlender-astrology-version-2
- Закрытый рабочий репозиторий: https://github.com/ivashkov2022-droid/valeria-fridlender-astrology-version-2-source

## Локальная работа

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

## Проверка и публикация

```bash
npm run build
npm run build:pages
```

- `app/` — исходники основной версии сайта.
- `public/` — фотографии и служебные изображения.
- `docs/` — готовая статическая сборка для GitHub Pages.
